# DevConf

DevConf is a responsive developer conference website designed to showcase speakers, conference tracks, schedules, venue information, registration plans, and event announcements.


## 🛠️ Tech Stack

* HTML5
* CSS3


## ✨ Features

* 🎤 Speaker showcase
* 📅 Conference schedule
* 🧑‍💻 Different conference tracks
* 📍 Venue information
* 🎟️ Registration plans and pricing
* ❓ FAQ section
* 📢 Latest announcements
* 📱 Responsive design

## 💻 Run Locally

Since this is a static HTML project, no package installation is required.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_LINK
```

### 2. Navigate to the project

```bash
cd Assignment01
```

### 3. Run the project

Open `index.html` directly in your browser.
